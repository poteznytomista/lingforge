# LingForge

An offline language-construction desktop workspace for Linux and Windows.

**Start with the [LingForge guide](docs/GUIDE.md)** for the AppImage location and launch command, features, saving/recovery, dependencies, development, actual test results and remaining work. Updated 2026-11-19.

The Linux AppImage runs and has passed 34 bounded native checks. Advanced editors remain experimental; Windows and full release acceptance are incomplete. Resources and PDF publishing are not completed features.

[Architecture](ARCHITECTURE.md) · [Roadmap status](ROADMAP.md) · [Technical specifications](docs/GUIDE.md#technical-reference)

The [download website](website/README.md) is prepared for GitHub Pages. Its local AppImage is at `website/downloads/LingForge_0.1.0_amd64.AppImage`. Generated build caches were removed at the user’s request; use `npm ci` and normal locked builds before development.
