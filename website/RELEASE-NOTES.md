# LingForge 0.1.0 — experimental Linux preview

An offline desktop workspace for constructed languages: lexicon, phonology, project archives and snapshots, with experimental writing systems, grammar/documents, glyph authoring, fonts/shaping and linguistic automation.

This is a development preview, not a fully accepted stable release. The Linux x86_64 AppImage passed 34 bounded native checks on the development Arch machine. Complete native acceptance and Windows validation remain unfinished. Resources and PDF export are not available. Use disposable projects and keep independent archives of important work.

The tested NVIDIA system needs `WEBKIT_DISABLE_DMABUF_RENDERER=1`. See the website's Linux launch notes. A compatible Linux runtime and possibly FUSE 2 compatibility are required. Rust and Node are not required to run the AppImage.
