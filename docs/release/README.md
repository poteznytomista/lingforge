# Release preparation entry point

Use the current [packaging and distribution guide](../GUIDE.md#packaging-and-distribution), [verified results](../GUIDE.md#verified-results) and [remaining acceptance](../GUIDE.md#remaining-acceptance). Genuine reviewed lockfiles and exact toolchain pins are required; never fabricate locks.

The [release checklist](CHECKLIST.md) remains the detailed evidence template. Linux has a tested experimental AppImage; Windows, complete native acceptance, signing/licensing and public distribution are unfinished. No public release is certified.
